🚀 Augment Conversation Manager

Production-ready data management system for Augment conversation exports with Redis caching, PostgreSQL storage, and automatic deduplication

⚡ Quick Start

# 1. Setup (starts PostgreSQL + Redis, installs dependencies)
./setup-conversation-manager.sh

# 2. Test (verifies everything works)
python3 test-conversation-manager.py

# 3. Import your first conversation
python3 conversation_manager.py import "conversation_export.json"

✨ Features

⚡ Redis Caching

Write-through caching pattern with 1-hour TTL for blazing-fast access to frequently used data.

🗄️ PostgreSQL Storage

JSONB support for flexible querying of nested conversation data with full-text search.

🔒 Deduplication

SHA256 content hashing prevents duplicate imports at conversation, message, and tool state levels.

🔍 Full-Text Search

Search conversations by name with PostgreSQL trigram indexes for fast, fuzzy matching.

🖥️ CLI Interface

Easy-to-use command-line interface for importing, searching, and analyzing conversations.

🐳 Docker Deployment

One-command setup with Docker Compose - PostgreSQL and Redis ready in seconds.
